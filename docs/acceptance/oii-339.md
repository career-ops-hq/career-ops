# OII-339 application lifecycle

The Python LangGraph `validate -> commit` path preserves the Node lifecycle
states, forward-only transitions, activities, outcome mapping, follow-up views,
and confirmed-package versus actual-submission boundary. A submission event now
references the exact confirmed apply result; views expose current opportunity
facts, retained artifacts, and that package's file hashes. Ambiguous multiple
confirmed packages require an explicit result key instead of silently choosing
the newest one.
The prior Node follow-up cadence has a Python counterpart over canonical
application and sent-activity dates: profile/default intervals, urgency,
overdue filtering, cold cutoff, next-date overrides and retirement/reopening.
Submission date prefers the explicit confirmed field, then a valid own date
in submission notes (excluding sibling-row citations), as in the Node report.
Unknown submission dates use a labelled legacy evaluation-date proxy when
available, then an opportunity-date or record-date proxy; no computed date is
presented as an observed submission date.
Follow-up views also retain the job URL, optional intermediary, submission
notes, dated sent-history, and the latest retained score/report key and hash.
Contact extraction is intentionally absent under the user's OII-341 decision;
missing score evidence stays null rather than becoming a fabricated value.

The isolated lifecycle regression covers valid and invalid transitions,
outcomes, activities, conflicting idempotency keys, legacy event reads, and
replay after deleting a checkpoint while the business result remains. Node
syntax, the Node opportunity-store test, and the Python scan/score handoff
regression pass. A separate fixed-date cadence regression covers the schedule,
retire and later-follow-up revival precedence.

The operational store has no submitted application, and on 2026-09-27 the
candidate confirmed there is currently no real submitted record to use. The
required real submitted-to-outcome path therefore remains unverified. Do not
manufacture a submission from a confirmed materials package, mark this issue
Done, or resume schedules on the strength of synthetic tests.
