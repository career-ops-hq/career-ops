# Historical evidence

`acceptance/` and `migrations/` retain the original documents from
`docs/acceptance/` and `docs/migrations/`. `workflow-runtime.md` retains the former
workflow README. Their bytes and historical command names are preserved; relative
links describe the original checkout layout. Current operation instructions are
in `../operations.md`.

Local evidence in `data/acceptance/`, captured sources, historical reports,
backups, and research scratch files stays at its original path when a persisted
record or manifest references it. Code cleanup does not authorize deleting it.
