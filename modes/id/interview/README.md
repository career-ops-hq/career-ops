# Skill Wawancara

Sekumpulan skill yang dapat dipakai ulang untuk persiapan wawancara dari awal hingga akhir.

## Skill

| Skill | File | Kapan digunakan |
|---|---|---|
| Perencana Persiapan | `plan.md` | Berdasarkan JD dan tanggal wawancara, susun rencana persiapan terstruktur dengan blok waktu |
| Pewawancara Latihan | `practice.md` | Jalankan pertanyaan wawancara latihan dengan feedback terstruktur |
| Debrief Pasca-Wawancara | `debrief.md` | Setelah wawancara sebenarnya, tutup kesenjangan dan perbarui question bank |

## Skill Terkait (di folder induk `modes/`)

| Skill | File | Kapan digunakan |
|---|---|---|
| Riset Perusahaan | `../../interview-prep.md` | Riset perusahaan dan role tertentu sebelum wawancara |

## Konvensi File

Skill ini mengasumsikan file berikut tersedia (default career-ops):

| File | Fungsi |
|---|---|
| `cv.md` | CV kandidat — sumber kebenaran untuk pengalaman dan proof points |
| `article-digest.md` | Proof points ringkas dari portofolio (opsional) |
| `config/profile.yml` | Profil kandidat — target role, kompensasi, narasi |
| `modes/_profile.md` | Archetypes, narasi, dan deal-breakers kandidat |
| `interview-prep/story-bank.md` | Kumpulan cerita STAR+R |
| `interview-prep/question-bank.md` | Question bank dengan pelacakan kesenjangan (dibuat saat pertama kali digunakan) |
| `interview-prep/interview-prep-guide.md` | Prinsip umum wawancara (opsional) |
| `interview-prep/{company}-{role}.md` | File persiapan untuk role tertentu |
| `interview-prep/sessions/*.md` | Transcript per round; front matter `stated_priorities` opsional (prioritas role yang disebutkan pewawancara) ditulis oleh debrief, dibaca oleh plan dan practice |
| `interview-prep/retracted-claims.md` | Claims yang ditolak kandidat karena tidak dapat dipertahankan — hard gate di practice dan debrief (format: `**"[claim]"** ([context]). Reason: [one-line reason + correct framing if applicable].`) |
