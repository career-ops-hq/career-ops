# Навыки для собеседований

Набор переиспользуемых навыков для подготовки к собеседованию от начала до конца.

## Навыки

| Навык | Файл | Когда использовать |
|---|---|---|
| План подготовки | `plan.md` | По описанию вакансии (JD) и дате собеседования построить структурированный план подготовки с тайм-блоками |
| Практический интервьюер | `practice.md` | Провести практические вопросы собеседования со структурированной обратной связью |
| Разбор после интервью | `debrief.md` | После реального собеседования закрыть пробелы и обновить question bank |

## Связанные навыки (в родительской папке `modes/`)

| Навык | Файл | Когда использовать |
|---|---|---|
| Исследование компании | `../interview-prep.md` | Изучить конкретную компанию и роль перед собеседованием |

## Соглашения о файлах

Эти навыки предполагают, что существуют следующие файлы (по умолчанию в career-ops):

| Файл | Назначение |
|---|---|
| `cv.md` | CV кандидата — источник истины об опыте и proof points |
| `article-digest.md` | Краткие proof points из портфолио (опционально) |
| `config/profile.yml` | Профиль кандидата — целевые роли, компенсация, narrative |
| `modes/_profile.md` | Archetypes кандидата, narrative и deal-breakers |
| `interview-prep/story-bank.md` | Накопленные истории STAR+R |
| `interview-prep/question-bank.md` | Question bank с отслеживанием пробелов (создаётся при первом использовании) |
| `interview-prep/interview-prep-guide.md` | Общие принципы собеседований (опционально) |
| `interview-prep/{company}-{role}.md` | Файл подготовки к конкретной роли |
| `interview-prep/sessions/*.md` | Transcripts по раундам; опциональный front matter `stated_priorities` (приоритеты роли, названные интервьюером) — записывает debrief, читают plan и practice |
| `interview-prep/retracted-claims.md` | Утверждения, которые кандидат отклонил как незащитимые, — hard gate в practice и debrief (формат: `**"[claim]"** ([context]). Reason: [one-line reason + correct framing if applicable].`) |
