# Навички для співбесід

Набір навичок, які можна використовувати повторно для підготовки до співбесіди від початку до кінця.

## Навички

| Навичка | Файл | Коли використовувати |
|---|---|---|
| Планувальник підготовки | `plan.md` | Маючи опис вакансії (JD) та дату співбесіди, побудувати структурований план підготовки, розбитий на часові блоки |
| Інтерв'юер для практики | `practice.md` | Провести тренувальні питання співбесіди зі структурованим відгуком |
| Аналіз після співбесіди | `debrief.md` | Після реальної співбесіди закрити прогалини та оновити банк питань |

## Пов'язані навички (у батьківській директорії `modes/`)

| Навичка | Файл | Коли використовувати |
|---|---|---|
| Дослідження компанії | `../interview-prep.md` | Дослідити конкретну компанію та роль перед співбесідою |

## Умовні позначення файлів

Ці навички передбачають, що існують такі файли (стандартні для career-ops):

| Файл | Призначення |
|---|---|
| `cv.md` | CV кандидата — джерело істини щодо досвіду та доказів досягнень |
| `article-digest.md` | Стислі докази досягнень із портфоліо (опціонально) |
| `config/profile.yml` | Профіль кандидата — цільові ролі, компенсація, життєпис |
| `modes/_profile.md` | Архетипи кандидата, життєпис і критичні чинники (deal-breakers) |
| `interview-prep/story-bank.md` | Накопичені історії STAR+R |
| `interview-prep/question-bank.md` | Банк питань із відстеженням прогалин (створюється під час першого використання) |
| `interview-prep/interview-prep-guide.md` | Загальні принципи підготовки до співбесід (опціонально) |
| `interview-prep/{company}-{role}.md` | Файл підготовки до конкретної ролі |
| `interview-prep/sessions/*.md` | Транскрипції окремих раундів; необов'язкове поле `stated_priorities` у frontmatter (пріоритети ролі, озвучені інтерв'юером) записує debrief, а читають plan і practice |
| `interview-prep/retracted-claims.md` | Твердження, які кандидат відкликав як такі, що не підлягають захисту — суворе обмеження (hard gate) у practice та debrief (формат: `**"[claim]"** ([context]). Reason: [one-line reason + correct framing if applicable].`) |
