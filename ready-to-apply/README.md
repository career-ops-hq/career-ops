# Ready to apply

This folder contains convenience copies of final application documents for manual upload to employer application sites.

- `output/` remains the Career-Ops source of truth.
- Place files here only after the resume or cover letter has passed the Career-Ops fact gate and the user has approved it.
- Updating a source document does not automatically update an existing copy in this folder. Recopy the approved source before using it when the source has changed.
