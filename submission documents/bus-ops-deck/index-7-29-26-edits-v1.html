Live Execution Trace

The system doesn't just run - it proves it ran.

Before: silent failure

Jobs could miss, stale data could accumulate, and the executive only discovered issues after they became visible.

After: controlled execution loop

The system logs state, refreshes stale artifacts, evaluates material change, and escalates only when a decision is required.

A cron job fires, reads status.json, captures the blocker, compares against history, and writes a health artifact. The business value is a provable operating rhythm.

[EVAL] material change? NO → suppress escalation

Infrastructure Layer

The homelab runs on infrastructure I built and operate myself.

a dual-network DNS/DHCP appliance on repurposed hardware — corporate sustainability, practiced

🌱 Sustainability as strategy, not slideware

A retired 2013 MacBook Pro rebuilt as a production Debian/Pi-hole appliance serving DNS and DHCP across two independent ISP networks. Resourcefulness and ingenuity over procurement — the circular-value lens from my Harvard Corporate Sustainability & Innovation training, applied to real infrastructure.

🔬 Ground truth over misleading signals

Diagnosed a degraded WiFi link by separating bogus driver-reported values from real radio statistics — the fault was physical placement, not configuration. Boot persistence was verified before the move, not hoped for after.

🔁 Lease migration, verified from both sides

Migrated DHCP authority from the ISP gateway using authoritative lease reclaim and tag-scoped dnsmasq ranges — then verified the full DHCP handshake in server logs and from the client side, proving ad-blocking end-to-end on both networks. Zero data loss.

🌐 Remote-only, including the failure case

Administered entirely over SSH and Tailscale — and when the box went dark after relocation, diagnosed the root cause (static-only WiFi, no default route → no VPN either) and reasoned back in from the client side via a second machine on the same LAN.

[DIAG] iw station dump → signal -97 dBm · retries 48/64
[EVAL] driver value bogus → trust radio stats
[FIX] clean poweroff → relocate hardware
[SSH] debby dark: wifi static-only, no route
[RECOVER] 2nd machine on LAN → ssh static IP → in
[VERIFY] signal -41 dBm → link stable
[DHCP] authoritative → stale gateway leases NAK'd
[VERIFY] DISCOVER→OFFER→REQUEST→ACK → pihole answers
[VERIFY] blocked domain → 0.0.0.0 on both networks
────────────────────────────────
✓ dual-network migration complete · zero data loss
