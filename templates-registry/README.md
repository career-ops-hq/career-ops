# templates-registry

The curated template-pack registry: one `<id>.json` per pack, each pinned to the exact commit a maintainer reviewed. It is the analog of `plugins-registry/`. A pack is registered by its own PR (use the `template-registry.md` PR template).

Check the shape with `node validate-template-registry.mjs`. Design: [#1778](https://github.com/career-ops-hq/career-ops/issues/1778), this directory: [#5947](https://github.com/career-ops-hq/career-ops/issues/5947).
