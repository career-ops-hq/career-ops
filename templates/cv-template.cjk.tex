% License: MIT
%
% Adds xeCJK + a CJK font so Chinese/Japanese/Korean content renders.
% Requires a XeTeX-based engine — pdflatex has no Unicode font support and
% cannot compile this file. Locally that means the tectonic engine; on
% Overleaf, set Menu -> Compiler -> XeLaTeX (Overleaf's default pdfLaTeX
% compiler cannot build this file either). generate-latex.mjs does NOT
% select this template automatically — you must explicitly generate from
% it: `node build-cv-latex.mjs <input.json> <output.tex> --template=cjk`.
% See #3553.
%
% Font requirement: \setCJKmainfont below names a font that must be
% installed system-wide (fontspec/xeCJK read the OS font list via
% fontconfig — tectonic does not bundle or download fonts). "Noto Serif
% CJK SC" is a widely available free choice (Google Noto CJK); swap it
% for any installed CJK-capable font (e.g. "Noto Sans CJK JP" for a
% sans-serif look, "Microsoft YaHei" on Windows, "Hiragino Mincho ProN"
% on macOS) if it is not present on your system.
%
% Keep in sync with cv-template.tex: this file mirrors it byte-for-byte
% apart from the CJK preamble block below, INCLUDING the %%%% banner
% comments cv-sections-core.mjs's stripEmptySections() matches on to drop
% empty optional sections (Projects/Education/Awards/Skills). Renaming or
% reordering a banner here without updating cv-template.tex breaks that.
%------------------------
